INSTRUCCIONES DE INSTALACIÓN Y DESPLIEGUE LOCAL

Siga estos pasos para descargar, configurar y ejecutar el proyecto por primera vez en su equipo, así como los comandos necesarios para su uso recurrente.

1. DESCARGAR EL PROYECTO
Abra su terminal (o línea de comandos) y descargue el repositorio. Luego, ingrese a la carpeta del proyecto:
git clone git@github.com:ProyectoInvestigacion/PaginaWeb.git
cd PaginaWeb

2. CONFIGURACIÓN INICIAL (Solo la primera vez)
El proyecto requiere un archivo oculto con variables de entorno para configurar la base de datos y la aplicación. Cree este archivo copiando la plantilla que ya viene incluida:
cp env.docker.example .env

(Puede abrir el archivo `.env` resultante en un editor de texto si necesita ajustar contraseñas, aunque los valores por defecto son suficientes para pruebas locales).

3. PRIMERA EJECUCIÓN (Compilar y Levantar)
Como es la primera vez, Docker necesita descargar las tecnologías y construir el servidor (Gunicorn). Ejecute el siguiente comando:
docker compose up -d --build

(El comando tardará un poco la primera vez. El parámetro "-d" asegura que el servidor corra en segundo plano, dejándole la terminal libre).
La página web estará disponible en: http://localhost:5000/

4. DETENER LA APLICACIÓN
Cuando deje de trabajar en el proyecto y quiera apagar el servidor para no consumir recursos en su computadora:
docker compose stop

5. VOLVER A LEVANTAR LA APLICACIÓN (Usos posteriores)
Para los días siguientes, dado que el proyecto ya fue construido en el paso 3, solo necesita encender los contenedores con un comando más rápido:
docker compose start

6. VERIFICAR LOGS Y REINICIAR
Si necesita ver lo que ocurre en el servidor o revisar posibles errores:
docker compose logs -f web1

Si necesita reiniciar el servicio para aplicar algún cambio rápido:
docker compose restart web1

7. DESTRUIR LOS CONTENEDORES (Opcional)
Si desea eliminar los contenedores activos (esto mantiene intacta su base de datos y su código, pero limpia la máquina virtual de Docker):
docker compose down
